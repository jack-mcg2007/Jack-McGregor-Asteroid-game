Download all files and folders and open in VS code, click run to build and launch game. 
game instructions:
Press space when prompted to start the game
use WASD to move the spaceship up down left and right and attempt to dodge asteroids, score will increase the longer you survive.
once hit you are taken to the game over screen. where your score is displayed, press r to restart.
notes - Makefile and .vscode folder contain code to help with compiling and building not created by me, but rather came included in the raylib download.
